# 2026-11-03 | 응답 데이터 검증 학습

## 오늘 배운 내용

Pydantic의 description은 필드에 대한 설명이다.
description에 범위를 적어도 실제 값의 범위가 제한되지는 않는다.

실제 검증에는 Literal과 Field의 제약 조건을 사용한다.

| 코드 | 의미 |
|---|---|
| Literal["normal", "focused", "completed"] | 지정한 상태 세 가지만 허용 |
| ge=-5 | -5 이상 허용 |
| le=5 | +5 이하 허용 |
| strict=True | 정수 필드에서 문자열 등의 자동 변환을 허용하지 않음 |

ge와 le를 함께 적용하면 -5 이상 +5 이하가 된다.
경계인 -5와 +5도 포함한다.

## 헷갈렸던 부분과 정정

- ge는 0~5를 뜻하지 않는다. 하한을 지정한다.
- le는 -5~0을 뜻하지 않는다. 상한을 지정한다.
- strict=True는 문자열을 그대로 허용하는 설정이 아니다.
- 정수 필드에서 정수 3은 허용하지만 문자열 "3"은 거부한다.
- 한 번의 변화량 제한과 누적 예제 상태 점수의 범위 제한은 별개다.
- 데이터 검증을 추가해도 서버 저장 기능이 생기지는 않는다.

## 예제 실행

이 폴더에서 실행한다.

```bash
python -m pip install "pydantic>=2,<3"
python validation_basics.py
```

API 키와 인터넷을 사용하는 LLM 호출은 필요하지 않다.
패키지 설치에는 인터넷이 필요할 수 있다.
