나:다음단계로 넘어가줘

제미나이:구상이 끝났다면 이제 **"작은 것부터 빠르게 만들고 엮는" 5단계 실행 로드맵**으로 들어가면 됩니다. 화면(프론트엔드)부터 만들면 개발이 지치기 쉬우므로, 백엔드의 파이썬 핵심 로직부터 단계별로 완성해 나가는 순서를 추천합니다.

---

### 1단계: 파이썬 핵심 프롬프트 & JSON 파싱 검증 (1~2일)

화면(UI) 없이 파이썬 터미널(`main.py`) 환경에서 프롬프트와 LLM 응답이 제대로 나오는지 먼저 테스트합니다.

1. **JSON Output 파싱**: LLM 응답이 `{"outer_speech": "...", "inner_thought": "...", "state_update": {...}}` 형태로 정확히 들어오는지 확인합니다.
2. **상태 라벨 반환**: 대화 흐름에 따라 상태 라벨(`normal`, `focused`, `completed`)이 정상적으로 갱신되는지 테스트합니다.

### 2단계: 대화 기억(Memory) 관리 로직 결합 (1~2일)

1. **슬라이딩 윈도우 + 요약(Summarizer)** 코드를 1단계 코드에 붙입니다.
2. 터미널에서 대화를 10~20회 연속으로 입력해 보고, 토큰 수가 비대해지지 않으면서 이전 대화 내용(유저 이름, 전달받은 퀘스트)을 계속 기억하는지 검증합니다.

### 3단계: FastAPI 백엔드 API 서버 구축 (2~3일)

1. 검증된 파이썬 스크립트를 `FastAPI` 엔드포인트(`/api/v1/chat`)로 변환합니다.
2. **Pydantic** 모델로 요청/응답 타입을 체계화합니다.
3. Database(PostgreSQL/SQLite 또는 Redis)를 붙여 유저 세션별 대화 기록과 예제 상태 점수 스코어를 저장합니다.
4. **SSE(Server-Sent Events)** 기술을 적용해 LLM 응답이 실시간 스트리밍되도록 연동합니다.

### 4단계: React 프론트엔드 UI 제작 및 이미지 연동 (3~4일)

1. React(Vite) 프로젝트를 생성하고 기본 대화 UI(채팅창, 입력폼)를 만듭니다.
2. **동적 이미지 교체**: 백엔드에서 넘어오는 `response_state` 값에 따라 응답 도우미 사진(`state_normal.png`, `state_focused.png`, `state_completed.png`)이 변경되도록 프론트엔드 상태를 연결합니다.


3. **이중 레이어 연동**: 주 응답은 일반 말풍선으로, 보조 설명(보조 설명)은 밑에 옅은 이탈릭체나 탭 형태로 연출합니다.


### 5단계: Docker 배포 & GitHub README 정돈 (2일)

1. Dockerfile을 작성하여 백엔드/프론트엔드 컨테이너 환경 구축 후 배포(AWS, Vercel, Render 등)합니다.
2. GitHub 리포지토리에 커밋 히스토리를 정돈해 올리고, **시연 GIF + 아키텍처 다이어그램 + 토큰 절감 성과**가 담긴 README를 작성합니다.
