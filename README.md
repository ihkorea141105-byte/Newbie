# LLM 응답 도우미 대화 API 포트폴리오

주 응답·보조 설명·상태·예제 상태 점수 변화를 JSON으로 생성하는 Python/FastAPI 초기 시제품입니다.

## 대표 프로젝트

**대화 API 학습 예제 — 응답 도우미 대화 API**

- 핵심 코드: [app.py](portfolio/2026-11-1/try1/app.py)
- 기술: Python, FastAPI, Groq SDK, Pydantic, python-dotenv
- 현재 범위: 백엔드 API 코드 구현. 외부 공개 웹 서비스와 성능 검증은 진행 전입니다.

## 코드에서 확인되는 구현

| 항목 | 현재 구현 |
|---|---|
| 대화 요청 | POST /api/chat에서 입력과 전달받은 대화 이력 처리 |
| 모델 호출 | 동기 Groq 클라이언트 호출 |
| 응답 처리 | JSON 파싱 및 Pydantic 필드 검증 |
| 오류 처리 | 파싱·검증 실패 시 기본 대사 반환 |
| 응답 도우미 표현 | 주 응답·보조 설명·상태 라벨 및 이미지 파일명 반환 |
| 예제 상태 점수 | 요청 점수와 모델이 반환한 변화량 합산 |
| 키 관리 | 서버 환경 변수에서 API 키 로드 |

## 현재 한계와 개선 계획

- 비동기 LLM 호출과 SSE 스트리밍은 미구현입니다. 현재는 전체 응답을 받은 뒤 JSON으로 반환합니다.
- 대화 이력·점수는 클라이언트 요청에 의존하며 DB 영구 저장, 서버 세션, 요약 기억은 미구현입니다.
- 상태 값과 예제 상태 점수 변화 범위는 추가 검증이 필요합니다.
- 이미지 파일명을 반환하지만 이미지 제공 서버와 프론트엔드 연결은 아직 구현하지 않았습니다.
- 상태별 파일명 반환 구조만 남겼으며 이미지 파일은 포함하지 않습니다.
- 토큰 절감률과 응답 시간 개선율은 아직 측정하지 않았습니다. 호출 횟수 감소만으로 비용 절감률을 단정하지 않습니다.
- React Query, Redis, Docker 배포 등 학습 기록의 제안은 구현 성과에 포함하지 않습니다.

## 평가 계획

동일한 모델·입력·설정으로 프롬프트 변경 전후를 반복 비교합니다. JSON 검증 실패율, 설정 일관성, 기억 정확도, 응답 시간, 입력·출력 토큰을 기록합니다. 요약 기능 추가 시 요약 호출 비용도 포함합니다. 결과가 확보된 뒤 표본 수와 조건을 함께 공개할 예정입니다.
